# 自动修图机

本地批量 AI 自动修图工具，支持大量图片导入、自动队列处理、RAW 支持、原图/成品对照、诊断日志和成品下载。

## 启动

双击 `start.bat`，然后打开：

```text
http://127.0.0.1:8000
```

## 支持格式

普通图片：JPG、PNG、TIFF、WEBP、BMP。

RAW 图片：DNG、NEF、CR2、CR3、ARW、ORF、RW2、RAF、PEF、SRW 等。

## RAW 处理策略

- 优先使用 `rawpy` / LibRaw 做半尺寸高质量 RAW 解码。
- 如果完整 RAW 解码失败，会尝试读取相机内嵌 JPEG 预览继续处理。
- 超大图默认压到约 16MP 输出，适合批量处理，避免卡死。
- 处理失败时页面会显示诊断信息，可点“诊断”查看 RAW 是否能打开、缩略图是否存在。

## 修图内容

- 自动白平衡
- 自动曝光和局部对比
- 自动审美参考
- 多候选修图方案评分
- 肤色保护
- 偏色、过饱和、过曝护栏
- 智能降噪和细节锐化
- 高质量 JPEG 输出

处理后的文件保存在 `workspace/outputs`。
